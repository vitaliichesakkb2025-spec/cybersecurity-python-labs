## Інструкція із запуску

### Windows (PowerShell)

#### 1. Створення віртуального середовища

```powershell
python -m venv .venv
```

#### 2. Активація віртуального середовища

```powershell
.\.venv\Scripts\Activate.ps1
```

#### 3. Встановлення залежностей

```powershell
python -m pip install -r requirements.txt
```

#### 4. Запуск лабораторної роботи

```powershell
python -m labs.lab01.main --seed 12
```

---

### Linux / macOS

#### 1. Створення віртуального середовища

```bash
python3 -m venv .venv
```

#### 2. Активація віртуального середовища

```bash
source .venv/bin/activate
```

```bash
python -m pip install -r requirements.txt
```

#### 4. Запуск лабораторної роботи

```bash
python -m labs.lab01.main --seed 12
```

## Параметри варіанта 12

### Завдання 1 — Аналізатор стійкості паролів

* Мінімальна довжина пароля — **9 символів**.
* Обов'язкова наявність **цифри**.
* Обов'язкова наявність **великої літери**.
* Обов'язкова наявність **спеціального символу**.

### Завдання 2 — Багаторівнева система контролю доступу

* **5 користувачів**.
* **10 ресурсів**.
* **4 рівні безпеки:**

  * `Sandbox`
  * `Development`
  * `Secure`
  * `Production Critical`
* Виконується перевірка **заблокованих облікових записів**.

### Завдання 3 — Хешування та журналювання

* Алгоритм хешування — **MD5**.
* Мінімальна довжина пароля — **8 символів**.
* Персональна сіль — `00012`.
* Використовується **CSV-база даних**.
* Ведеться **JSON-журнал** подій.
* Реалізовано **декоратор** для журналювання.

---

## Примітка щодо безпеки

Алгоритм **MD5** та статична спільна сіль `00012` використані виключно відповідно до вимог навчального завдання.

У реальних системах кібербезпеки **MD5 не слід використовувати для зберігання паролів**. Для цього необхідно застосовувати сучасні алгоритми, призначені для password hashing, наприклад **Argon2id** або **bcrypt**, із використанням унікальної солі для кожного пароля.
